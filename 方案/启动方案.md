## 命理咨询副业 · 启动方案

### 一、产品线

#### 主推：八字简批（88元）

**包含内容：**
- 八字排盘（四柱 + 十神 + 藏干 + 五行）
- 身强身弱判断 → 喜用神/忌神
- 性格特质（3-5句话，说人话不背书）
- 事业/财运方向建议（2-3条具体建议）
- 当前大运 + 2026流年简要分析
- **交付物：** 1页A4 PDF报告（约800-1200字）

**交付时间：** 24小时内（实际30分钟可完成）

#### 升级版：深度详批（288元）

在简批基础上增加：
- 前几步大运回顾（验证准确度，建立信任）
- 未来3年流年趋势
- 婚姻/感情专项
- 健康注意
- **交付物：** 3-4页PDF（约2500-3500字）

#### 后续可开：
- 合盘/合婚（588元）— 两人八字+紫微合盘
- 紫微斗数全盘（388元）— 十二宫完整分析
- 流年专项（168元）— 单年深度分析

---

### 二、定价逻辑

| 价位 | 理由 |
|------|------|
| **88元简批** | 门槛低，冲动消费区间。比同行（普遍128-268）低一档，走量 |
| **288元详批** | 价值感翻3倍，但工作量只翻1.5倍。是利润主力 |
| **第一单特价** | 可以考虑 38-58元 破零，拿到第一个好评 |

**为什么你的成本极低：**
- 排盘：Python脚本自动输出，1秒完成（同行手动排盘10-15分钟）
- 解盘：DeepSeek AI辅助分析，5-10分钟出解读
- 排版：模板化PDF，3分钟套入
- **单均耗时：15-30分钟，时薪 176-352元（按88元算）**

### 三、工具链

```
客户提供生辰 → bazi_universal.py 排盘 → DeepSeek AI解盘 → PDF报告交付
                                     ↓
                              你审阅润色（5分钟）
```

**操作步骤：**

1. **收集信息**（复制发给客户）：
   > 请提供以下信息：
   > 1. 公历出生日期（年/月/日）
   > 2. 具体出生时间（几点几分，尽量精确）
   > 3. 出生地（省份+城市）
   > 4. 性别
   > 5. 你最想了解什么？（事业/财运/感情/健康/整体）

2. **排盘**：
   ```bash
   python G:\ClaudeCode\.claude\scripts\bazi_universal.py [年] [月] [日] [时] [性别]
   ```

3. **AI解盘**：把排盘输出 + 以下 prompt 发给 DeepSeek：

   ```
   你是一位有20年经验的八字命理师。请根据以下命盘，写一份给普通人看的命理分析。

   要求：
   - 不说教科书术语，用大白话
   - 每个判断都要有依据
   - 给具体建议，不给空话
   - 语气像朋友聊天，真诚、不吓人
   - 控制在800-1200字
   - 结构：①性格特质 ②事业方向 ③财运走势 ④当前运势 ⑤给你的建议

   命盘如下：
   [粘贴排盘输出]
   ```

4. **审阅润色**：检查AI输出有没有明显错误（十神解读、五行判断），用你自己的语气改几处，去掉AI味。

5. **生成PDF交付**：用你熟悉的工具（WPS/Word）套模板输出PDF。

### 四、获客渠道

#### 渠道一：闲鱼（零粉丝起步，最推荐）

**标题模板（选一个）：**
```

```
```
传统八字命理简批|性格/事业/财运方向|不满意不收费
```

**正文：**
```
【关于我】
自幼跟随家传学习传统命理学，八字、紫微斗数均有研习。
非AI生成，真人手工解盘，每份报告都是用心写的。

【八字简批 88元】
包含：命盘排盘 + 性格分析 + 事业财运方向 + 当前运势
交付：1页PDF报告，24小时内发出
需要提供：公历出生年月日时、性别、出生地

【深度详批 288元】
包含简批全部内容 + 前几步大运回顾 + 未来3年趋势 + 婚姻专项
交付：3-4页完整报告

⚠️ 命理分析仅供参考，不作为人生决策的唯一依据
🔞 不看生死、不算赌博、不测非法之事

💬 拍前请先私聊确认，提供基本信息后开始排盘
```

**主图建议：**
- 用WPS/Canva做一个简洁封面："传统八字命理分析" + 太极图/八卦元素
- 不要用网图（跟别人撞图会被判同质化）
- 可以拍一张你的书桌/书的照片，增加真实感

**闲鱼运营要点：**
- 每天"擦亮"（刷新）一次
- 3天不出单就降价到58元破零
- 第一个客户认真服务，求个好评
- 有5个好评后恢复88元

#### 渠道二：小红书（内容引流）

**内容策略：** 不发广告，发"免费看盘"内容吸引精准用户。

**爆款选题（抄同行的爆款结构，换成你的内容）：**
1. "乙木女的性格特征，准得离谱" → 讲一个日主类型的特征
2. "命里带七杀的人，是不是真的命苦？" → 纠正一个常见误解
3. "怎么看自己八字里有没有财？手把手教" → 简单教学
4. "拉萨人看八字，跟你平原人看的还真不一样" → 结合你的地理位置

**每条笔记末尾：**
```
想了解自己的八字格局？
关注+评论「想看」，我随机抽3位免费简批
```

**前10条不发广告，纯干货。** 10条之后再开始引导私域（微信）。

#### 渠道三：微信朋友圈

**第一条朋友圈（立人设）：**
```

给几个朋友看了盘，反馈还不错。
```

不要一上来就发广告，先发2-3条"我在学这个"的内容铺垫。

### 五、风险规避

1. **免责声明**（每次交付附上）：
   > 以上分析基于传统命理学，仅供参考和娱乐。人生选择仍需结合现实情况独立判断，不宜作为唯一决策依据。

2. **不看的内容**（直接拒绝）：
   - 生死寿元
   - 赌博/彩票
   - 违法之事
   - 重疾医疗建议（让其找医生）

3. **定价别太低**：低于50元会吸引大量只想白嫖/找茬的人。88元是个不错的门槛。

4. **不承诺准确率**：说"仅供参考"不说"保证准确"

### 七、算一笔账

| 场景 | 单量/月 | 均价 | 月收入 |
|------|---------|------|--------|
| 保守 | 10单简批 | 88元 | **880元** |
| 中等 | 15单简批 + 3单详批 | — | **2,184元** |
| 稳定后 | 20单简批 + 5单详批 + 2单合盘 | — | **4,096元** |

就算只有10单/月，也够补贴1/6的月开支。而且这只是八字——后续加上紫微斗数和合盘，客单价翻倍。最重要的是，**这套系统几乎没有边际成本**，每一单的排盘和分析都靠脚本+AI完成，你只需要花几分钟审阅。
